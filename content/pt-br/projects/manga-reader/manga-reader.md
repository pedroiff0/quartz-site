# Manga Reader Web

> [!abstract] Brief do Projeto
> Aplicacao web responsiva desenvolvida para leitura de quadrinhos e mangás com suporte a navegacao fluida e modo escuro.

---

## Tecnologias Utilizadas

- **Frontend:** React / Next.js / TypeScript
- **Estilizacao:** Tailwind CSS
- **Performance:** Carregamento otimizado de imagens e renderizacao adaptativa.
