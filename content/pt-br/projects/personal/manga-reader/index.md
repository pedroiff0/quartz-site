# Suwayomi-Next (Private Custom Edition)

A modern, responsive web client for [Suwayomi-Server](https://github.com/Suwayomi/Suwayomi-Server) built with React 19, Vite, Tailwind CSS, and Shadcn UI.

---

### Credits & Attribution
**All core credits and recognition belong entirely to the official [Suwayomi](https://github.com/Suwayomi) team and the creators of [Suwayomi-Next](https://github.com/Suwayomi/Suwayomi-Next).**
This repository is configured for private and friends-only usage with added access control and administrative user management.

---

## Features

- **Auth & Access Control:** Private invite/registration system and user management dashboard.
- **Modern UI:** Built on top of Shadcn UI and Tailwind CSS.
- **Continuous Reader:** Fullscreen and continuous vertical Webtoon reading mode.
- **Multi-Source Support:** Seamless integration with Suwayomi-Server GraphQL endpoints.
- **PT-BR Ready:** Optimized for Portuguese manga and manhwa scanlations.

## Getting Started

```bash
# Clone
git clone <repo-url>
cd Suwayomi-Next

# Install dependencies
npm install

# Run dev server
npm run dev
```
