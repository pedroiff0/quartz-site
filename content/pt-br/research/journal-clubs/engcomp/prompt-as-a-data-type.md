> Um banco de dados que trata prompts de LLMs como um tipo de dado relacional, permitindo que o sistema os reescreva, otimize e gerencie nativamente.

_Martins, D. M. L. & Vossen, G. (2026)_

## Resumo
Modelos de Linguagem (LLMs) são cada vez mais usados com bancos de dados relacionais, mas os prompts ficam normalmente isolados fora do banco (em código), invisíveis para a otimização de queries e metadados. O "PromptDB" introduz o tipo de dado lógico `PROMPT`, permitindo que o otimizador de banco de dados reescreva os prompts para melhorar o custo-benefício e a precisão do uso das LLMs.
