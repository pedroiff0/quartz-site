> Un banco de datos que trata de prompts de LLMs como un tipo de dato relacional, permitiendo que el sistema los reescribe, otimice y administre entivamente.

 Martins, D. M. L. & Vossen, G. (2026) 

## Resumen
 Los modelos de lenguaje (LLMs) se usan cada vez más con bases de datos relacionales, pero los prompts suelen estar aislados fuera del banco (en código), invisibles para optimizar quéries y metadatos. El "PromptDB" introduce el tipo de dato lógico `PROMPT`, permitiendo que el optimizador de bases de datos reescribe los prompts para mejorar el costo-beneficio y la precisión del uso de las LLMs.
