## Résumé
 Les modèles de langage (LLM) sont de plus en plus utilisés avec les bases de données relationnelles, mais les appels sont souvent isolés en dehors de la banque (en code), invisibles pour optimiser les tremblements et les métadonnées. Le "ProptDB" introduit le type de données logique 'PROMPT', permettant à l'optimiseur de base de données de réécrire les invites à améliorer le rapport coût-efficacité et la précision de l'utilisation des LLM.
