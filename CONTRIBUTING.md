# Guia de Contribuição — Quartz Site (Digital Garden)

Agradecemos o interesse em contribuir com as notas e publicações do **Quartz Site**!

---

## 1. Organização do Conteúdo
- Todo o conteúdo reside em `content/` (espelhado do cofre Obsidian `hardcore-life`).
- Usar formatação em Markdown padrão compatível com Obsidian e Quartz v4.
- Metadados nos frontmatters: `title`, `tags`, `publish`, `description`.

---

## 2. Testes de Build Local
Antes de submeter alterações:
```bash
make dev
# ou
make build
```
